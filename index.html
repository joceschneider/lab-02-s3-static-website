O que é computação em nuvem?

É a disponibilização de recursos de tecnologia pela internet, sob demanda, sem a necessidade de manter toda a infraestrutura física localmente.

01 / Custos

Pagamento pelo uso

Utilize recursos conforme a necessidade e acompanhe os custos do consumo.

02 / Capacidade

Elasticidade

Ajuste a capacidade dos recursos de acordo com as variações da demanda.

03 / Infraestrutura

Disponibilidade

Utilize regiões e zonas de disponibilidade para projetar soluções resilientes.

Aula em foco

Amazon S3 — Simple Storage Service

Armazenamento de objetos escalável para sites, backups e dados.

99,999999999%Durabilidade projetada do S3 Standard
2006Ano de lançamento do Amazon S3

Buckets, objetos e keys

Bucket é o contêiner; objeto é o arquivo com seus metadados; key é seu identificador dentro do bucket.

Classes de armazenamento

S3 Standard para acesso frequente; Intelligent-Tiering ajusta camadas conforme o acesso; Glacier oferece opções de arquivamento.

Versionamento

Preserva versões de objetos e ajuda na recuperação de alterações ou exclusões acidentais.

Lifecycle

Regras automatizam transições de classe e expiração de objetos ou versões.

Criptografia e acesso

Novos objetos são criptografados por padrão. Políticas IAM e de bucket controlam acesso; mantenha acesso público bloqueado quando não necessário.

Hospedagem estática

Entrega HTML, CSS e JavaScript ao navegador, sem executar código de servidor.

Replicação

Permite copiar objetos de forma assíncrona para outro bucket, conforme configuração e requisitos.
